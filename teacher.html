Nhập từ vựng hàng loạt từ Excel / CSV

Kéo thả tệp Excel (.xlsx / .xls / .csv) vào đây hoặc bấm để chọn tệp
Hỗ trợ chuẩn 5 cột: Chữ Hán | Pinyin | Từ loại | Nghĩa tiếng Việt | Câu ví dụ. Chưa có file mẫu? Bấm Tải file Template (.xlsx) hoặc tab Xem file Template mẫu ở trên.
Xem trước dữ liệu (0 từ sẽ được thêm): Sẵn sàng nhập
# Chữ Hán Pinyin Từ loại Nghĩa tiếng Việt Câu ví dụ
Bảng mẫu chuẩn 5 cột (A–E) tương thích khi tải lên .xlsx, .csv hoặc copy-paste từ Excel:
Quy tắc nhập file Excel từ vựng: Cột A (Chữ Hán) và D (Nghĩa tiếng Việt) là nội dung chính; Cột B (Pinyin) nên điền kèm dấu thanh để hiển thị chuẩn trên thẻ Flashcard; Cột C (Từ loại) và E (Câu ví dụ) là tùy chọn (có thể để trống, hệ thống tự điền mặc định); có thể giữ nguyên dòng tiêu đề Chữ Hán | Pinyin | ... khi tải file lên hoặc dán bảng, hệ thống sẽ tự động bỏ qua dòng tiêu đề. Nếu chỉ copy nhanh 2 cột (Chữ Hán | Nghĩa) hoặc 3 cột (Chữ Hán | Pinyin | Nghĩa), hệ thống vẫn tự nhận diện chính xác.

Nhập Đề Luyện Tập Cuối Buổi Từ Excel

Kéo thả tệp Excel (.xlsx / .xls / .csv) vào đây hoặc bấm để chọn tệp
Hỗ trợ cả 6 dạng bài: Nối từ, Trắc nghiệm, Điền từ, Sửa câu sai, Dịch câu, Nghe hiểu. Chưa rõ cấu trúc cột? Bấm tab Xem file Template mẫu ở trên.
Xem trước đề được tạo: 0 phần 0 câu hỏi 0 điểm
Sẵn sàng nhập
Phần Dạng bài Tên phần Số câu Điểm Nội dung tóm tắt
Quy tắc điền nhanh trong Excel: Cột A (Dạng bài) nhập tên tiếng Việt (Nối từ, Trắc nghiệm, Điền từ, Sửa câu sai, Dịch câu, Nghe hiểu); nếu các dòng dưới thuộc cùng dạng/phần có thể để trống cột A hệ thống tự nối tiếp. Cột I (Đáp án đúng) luôn chứa đáp án (Nghĩa TV với Nối từ; A/B/C/D với Trắc nghiệm & Nghe hiểu; Từ điền với Điền từ; Câu sửa chuẩn ngăn cách / với Sửa câu sai & Dịch câu; để trống hoặc ghi thu_cong nếu muốn chấm tay câu Dịch). Với Nghe hiểu, cột D là ngữ cảnh bài nghe, cột J là giải thích đáp án (tùy chọn, hiện sau khi nộp bài), cột K là đường dẫn file audio (URL) — nếu dùng chung 1 link cho nhiều câu thì hệ thống tự chọn dạng 1 file nghe chung, nếu mỗi câu có 1 link audio riêng hoặc ghi Nghe từng câu ở cột A thì tự chọn dạng Mỗi câu hỏi 1 file nghe (hoặc tải file .mp3/.m4a/.wav hay ghi âm trực tiếp sau khi nhập).
